# Goal 
To deploy a static website and make it public using GitHub Pages, follow these step-by-step instructions.
- Anything that is manually i will do myself. Anything that is can be created without human intervention you job is to build it. 

#Steps: 
## Step 1: Prepare Your Website Files
Before uploading, ensure your local website folder contains your main HTML file and that it is explicitly named index.html. GitHub Pages requires this file to serve as the entry point (homepage) of your public website. [1] 
## Step 2: Create a Public GitHub Repository
Log in to your account on GitHub. [2] 
Click the + icon in the upper-right corner and select New repository. [2, 3] 
Give your repository a name (e.g., my-static-site). [2] 
Select Public as the visibility level. Note: GitHub Pages is free for public repositories. If you choose private, it requires a paid GitHub Enterprise plan. [2, 4, 5, 6] 
Click Create repository. [2, 3] 
## Step 3: Upload Your Files
If you are comfortable with Git, you can push your files using the terminal. If you prefer a quick, browser-based method:[7] 
On your new repository page, click the link that says uploading an existing file.
Drag and drop your website files (including index.html, CSS, and JavaScript files) directly into the browser window. [1, 5] 
Click Commit changes at the bottom of the page. [4, 8] 
## Step 4: Activate GitHub Pages
Navigate to your repository page on GitHub and click the Settings tab.
In the left-hand sidebar, locate the "Code, planning, and automation" section and click Pages.
Under the Build and deployment section, make sure the Source is set to Deploy from a branch.
Under Branch, change the dropdown selection from None to your primary branch (usually main or master). Leave the folder dropdown as /root.
Click Save. [1, 3, 5, 9, 10, 11, 12] 
🌐 Accessing Your Live Site
GitHub will take 1 to 5 minutes to build and publish your project. [3, 11] 
Once complete, refresh your Settings > Pages tab. You will see a live notice at the top saying: "Your site is live at..."followed by your public URL. The URL structure will follow this format:
https://<your-username>.github.io/<your-repository-name>/ [8, 9, 11, 12] 
Any future modifications you make or push to this repository will automatically trigger an update and redeploy the live website. [11] 
If you plan to use a custom domain name or want to know how to resolve broken asset paths (like broken images or CSS) on your new URL, let me know!
